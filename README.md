Códigos do Amanhã

Sobre o projeto
Este repositório reúne meus estudos, exercícios e projetos desenvolvidos durante minha participação no programa Códigos do Amanhã, 
uma iniciativa de formação em tecnologia promovida pelo EBANX em parceria com a How Bootcamps.

O programa tem como objetivo desenvolver habilidades técnicas na área de tecnologia, com foco em programação, análise e manipulação de dados.

Este repositório funciona como um registro da minha evolução técnica, reunindo atividades práticas, experimentos e projetos desenvolvidos ao longo da formação.

Tecnologias e ferramentas
- Python: fundamentos de programação e desenvolvimento.
- Pandas: manipulação, limpeza e transformação de dados.
- NumPy: operações e manipulação de dados numéricos.
- SQL: consultas e gerenciamento de bancos de dados.
- Git e GitHub: versionamento e organização de projetos.
- Web Scraping: extração de dados da web.
- Visualização de dados: exploração e apresentação de informações.

Conteúdos estudados: 
- Fundamentos de Python.
- Estruturas de dados e lógica de programação.
- Manipulação e análise de dados com Pandas.
- Visualização de dados.
- Leitura e escrita de arquivos.
- Tratamento de exceções e depuração.
- Módulos, pacotes e programação orientada a objetos.
- Introdução a Data Lakes e Data Warehouses.
- Consultas e manipulação de dados com SQL.

Organização do repositório
Os diretórios estão organizados para separar os conteúdos teóricos, exercícios e projetos práticos desenvolvidos durante a formação.

Objetivo
Consolidar conhecimentos em programação e dados por meio da prática, desenvolver autonomia na resolução de problemas e construir 
uma base técnica para atuar profissionalmente na área de Dados e Engenharia de Dados.

Status: Em desenvolvimento 📚

Este repositório será atualizado continuamente conforme meu avanço na formação.
